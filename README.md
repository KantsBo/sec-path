# SOC Path

Мобильное веб-приложение с моим планом обучения на SOC-аналитика (Blue Team).

**Что внутри**
- **Сегодня** — текущий этап, прогресс, распорядок дня и следующая цель
- **План** — 6 этапов с автоматическим отсчётом дней (21 ноября 2026 → июль 2027)
- **Серты** — SAL1, Security+, BTL1, затем SC-200 и CySA+
- **Комнаты** — все 55 комнат Cyber Security 101: 1 комната в день, воскресенье — выходной; опережение/отставание в комнатах
- **Чек** — график занятий и контрольные точки

Один файл `index.html`, без зависимостей. Отметки сохраняются в браузере (localStorage).

## Установка на iPhone
1. Открыть сайт в Safari (GitHub Pages).
2. «Поделиться» → «На экран „Домой“».
